## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\TarkovTrainer\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Key to toggle menu |
| `process_name` | String | `"EscapeFromTarkov.exe"` | Target process |
| `esp_enabled` | Boolean | `true` | Enable ESP |
| `aimbot_enabled` | Boolean | `false` | Enable aimbot |
| `safe_mode` | Boolean | `true` | Restricts risky features |
